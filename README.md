# 📖 Overview

This project is an **end-to-end AI-powered E-Commerce Sales Forecasting and Customer Analytics Platform** built using **Python, SQL, Machine Learning, Power BI, and Streamlit**.

The platform helps businesses analyze historical sales data, understand customer purchasing behavior, identify valuable customer segments using **RFM Analysis + K-Means Clustering**, forecast future sales, and make data-driven business decisions through interactive dashboards.

The project combines:

- Data Cleaning
- Exploratory Data Analysis (EDA)
- SQL Business Analytics
- Customer Segmentation
- Sales Forecasting
- Machine Learning
- Power BI
- Interactive Streamlit Dashboard

into one complete analytics solution.
